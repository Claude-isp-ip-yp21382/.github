<h2>二、地址与归属类参数</h2>
<p>这一类决定"看起来像不像真实用户"，是底层参数。</p>
<h3>地址类型：三种形态的实际差别</h3>
<p>原生家宽指地址登记在本地运营商宽带池、长期由家庭线路使用；双 ISP 指注册信息里挂了两家本地运营商的归属；机房段则是数据中心地址。三者在查询工具里的区别很直观：原生家宽的机构名是宽带品牌、类型为 ISP；双 ISP 会显示两条 ASN；机房段的机构名多为云服务商。订阅类业务优先原生家宽，预算宽松时选双 ISP 归属。</p>
<h3>ASN 归属：怎么看是否自洽</h3>
<p>查法：<code>curl -s ipinfo.io</code> 看 org 与 asn 字段，再用运营商官网核对品牌归属。合格的组合是城市、运营商、ASN 三者指向同一区域；不合格的典型是城市写洛杉矶、运营商却是东部的服务商。双 ISP 场景额外确认两条 ASN 是否都属于本地宽带商，一条家宽一条机房的组合没有意义。</p>
<h3>地址池规模与复用率</h3>
<p>这项参数很少写在报价单上，但要主动问。池子小于五百条的，容易出现"隔壁邻居"式的高频共用；复用率超过每地址每月三户的，长期保持登录态的稳定性会下降。合理的答复应该是具体的池子规模和当前分配数，而不是"资源充足"。</p>

<h2>三、连接与性能类参数</h2>
<p>这类参数决定"能不能顺畅跑"，和稳定性直接相关。</p>

<h3>带宽上限与实测方式</h3>
<p>常见标注是共享 10 至 100 Mbps，少数标不限。共享带宽要测晚高峰，方法是在目标时段下载一个 50 MB 文件，记录耗时换算速率。实测低于标注值一半的，说明争抢严重。单号日常对话与页面操作，20 Mbps 已经足够；跑批量导出或长文件传输，建议 50 Mbps 以上。</p>
<h3>并发连接数的实际影响</h3>
<p>参数写"限制 3 个连接"的，浏览器打开多个标签就可能占满，表现为部分请求排队超时。选至少 5 个，跑脚本或多标签操作选不限。测试方法：开五个并行的 <code>curl</code> 请求同一地址，看是否全部在合理时间内返回，有排队的就是并发被限。</p>
<h3>延迟与丢包的阈值</h3>
<p>跨境线路到美西稳定在 150 至 220 毫秒属正常，东南亚多在 60 至 120 毫秒。丢包低于 1% 可以接受，1% 至 3% 会在长连接上表现为偶发卡顿，超过 3% 就该换线。这些数字要用 <code>mtr -rw -c 100</code> 在本地高峰时段测，只看供应商给的截图没意义。</p>

<h2>四、会话与切换类参数</h2>
<p>这是订阅场景最容易被忽略、出问题又最麻烦的一组。</p>
<h3>会话保持时长</h3>
<p>必须选"固定"，即地址在订阅期内不变。按小时轮换的动态地址，对一次性抓取友好，对长期登录态是灾难——每次换地址都可能触发重新确认。合同里要写明"订阅期内地址不变"，并约定变更时的提前通知义务。</p>
<p>与保持时长绑在一起的是切换策略：自动轮换适合爬取，手动切换适合订阅。判断标准很简单——你是否需要知道"这个号此刻在哪个地址"，需要，就必须手动。另外确认切换的生效时间，合理值是几分钟内，需要等半天的没法应急。</p>
<h3>换环境重开的参数清单</h3>
<p>号被要求确认之后重开，按这个顺序调：先把该号切到一条未使用过的新地址（同城市、同运营商），再把浏览器配置重建（清空存储、重设时区语言）、降低并发到 1、关掉所有自动化任务登录一次、观察 24 小时后再恢复。整个过程不要在原地址上反复尝试。</p>

<h2>五、计费与续订类参数</h2>
<p>这一类决定长期成本和灵活性，容易被低价吸引而忽略约束。</p>
<h3>计费口径的三种形态</h3>
<p>按条包月，常见 80 至 200 元每条每月；按流量，常见 3 至 8 元每 GB；混合计费，基础月费加超出流量。订阅类业务流量平稳，按条包月更可预测；偶发大批量导出的，混合计费更省（以上价格仅供参考）。</p>
<h3>续订与退订条款</h3>
<p>要问清三件事：中途停用是否按剩余天数退费、能否在同价位内换资源、年付折扣对应的锁定期多长。常见门槛是三个月起租、年付八折。锁定期越长，资源质量下滑时的沉没成本越高，建议先月付跑满两个月再考虑长约。</p>

<h2>常见问答</h2>
<h3>"单账号独享一条出口"具体指什么？</h3>
<p>答：指这条地址在订阅期内只分配给你的这一个账号使用，其他客户不会同时占用。要落到合同里的三点是：地址固定不变、不与其他客户共享、并发与带宽不被他人挤占。只有第一条而没有后两条，独享就只是名义上的。</p>
<h3>会话保持参数为什么必须选固定？</h3>
<p>答：长期登录态依赖"地址不变"这个前提。地址轮换会让每次登录都像换了地方，容易被要求重新确认。除非你的用途是一次性抓取，否则一律选固定，并在合同里写明订阅期内地址不变。</p>
<h3>带宽标注 100 Mbps，实测只有 20 Mbps 正常吗？</h3>
<p>答：共享带宽在高峰时段打折是常态，但低于标注一半就偏低了。建议在晚八点到十一点复测，如果长期只有标注值的五分之一，属于资源超售，可以据此要求换线或退订。</p>
<h3>被要求确认之后，换环境重开要注意什么？</h3>
<p>答：换新地址、重建浏览器配置、把并发降到 1、只登录一次、观察一天。关键是不要在原地址上反复试，重复失败会把临时确认变成更严格的限制。恢复之后把该号固定到新地址，不再来回切换。</p>

<h2>合规提示</h2>
<p>参数核对与线路测试应限于自有或经授权运营的账号与环境，测试记录仅用于内部评估。不得将资源用于伪造访问来源、批量注册账号或规避平台规则。</p>
<p>签约前要求供应商以书面形式确认地址类型、ASN 归属、会话保持与退订条款，保留合同与账单。文中价格与性能区间为市场观察值，仅供参考，实际以合同和实测为准。</p>
